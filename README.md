# OSSign Information
## What's this?
This is a repository used for creating signed binaries for the [SpacingBat3/WebCord](https://github.com/SpacingBat3/WebCord/) project.

## Where are the signed binaries published?
The signed binaries are published by the author on [SpacingBat3/WebCord](https://github.com/SpacingBat3/WebCord).

You can find the latest workflow runs for the build and signing process in the [Actions tab](https://github.com/ossign/spacingbat3--webcord/actions).
